# Крестики-нолики с нейросетью - план

Спецификация: `docs/superpowers/specs/2026-09-26-tictactoe-ai-design.md`.

Каждая задача идёт по кругу: тест -> убедиться, что красный -> код -> зелёный -> коммит.
Все запуски тестов и обучения - с `OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4
MKL_NUM_THREADS=4` (процессор делят несколько обучений). Тесты Qt - с
`QT_QPA_PLATFORM=offscreen` из `tests/conftest.py`, без pytest-qt.

## Задача 1. Каркас

- `pytest.ini`, `requirements.txt` (numpy, PySide6), `requirements-dev.txt` (+ pytest),
  `tests/conftest.py` (offscreen, корень в `sys.path`, данные игры во временную папку).
- `paths.py`: ресурсы рядом с кодом или в `_MEIPASS`; данные в
  `%LOCALAPPDATA%\TicTacToeAi`, с `portable.txt` рядом с exe - в `saves` рядом;
  переменная `TICTACTOEAI_HOME` подменяет папку данных (тесты, самопроверка).
- Тесты `tests/test_paths.py`: подмена через переменную, portable-режим, обычный режим.
- Коммит «Каркас: pytest, пути к данным и ресурсам».

## Задача 2. Слои nn

- Скопировать из SnakeAIGame `nn/layers.py`, `nn/losses.py`, `nn/optim.py`, `nn/io.py`,
  `tests/test_nn.py`.
- Дописать: `Tanh`, `Flatten`, `Sequential` (forward/backward/params по списку слоёв),
  `losses.mse` (значение и градиент).
- Тесты: численные градиенты tanh, flatten, всей последовательности (свёртка -> ReLU ->
  flatten -> плотный -> tanh), mse; сохранение и загрузка весов всей сети.
- Коммит «Свои слои на numpy: из нейро-змейки, плюс tanh, flatten, последовательность, mse».

## Задача 3. Правила - `core/rules.py`

- Поле `np.int8` N x N: 0 пусто, 1 X, -1 O. Длина ряда: 3x3 -> 3, 5x5 -> 4.
- `new_board(n)`, `to_move(board)` (X ходит первым), `legal_moves`, `play` (занятая
  клетка или конец партии -> ошибка), `lines(n, k)` - все отрезки длины k индексами
  (кэш), `winner`, `winning_line`, `is_draw`, `outcome` (None - партия идёт).
- Тесты: победа по каждой строке, столбцу, обеим диагоналям на 3x3; на 5x5 четыре в ряд
  не от края (со второй клетки строки, в середине столбца, короткие диагонали), три в ряд
  на 5x5 - не победа; ничья; занятая клетка; чей ход; ход после конца партии.
- Коммит «Правила: поле, ходы, победа k в ряд, ничья».

## Задача 4. Боты - `core/bots.py`

- `RandomBot`, `WinOrBlockBot` (выиграть одним ходом, иначе помешать, иначе случайно),
  `MinimaxBot` для 3x3 (негамакс с памятью, случайный среди лучших ходов).
- `play_game(x_player, o_player, n)` -> (исход, ходы); `match(player, opponent, n,
  games, colors)` -> {wins, losses, draws} с точки зрения `player`.
- Тесты: бот ходит только в свободную; «выиграй или помешай» выигрывает и мешает;
  минимакс против минимакса - всегда ничья, минимакс не проигрывает случайному.
- Коммит «Боты для проверок: случайный, выиграй-или-помешай, минимакс 3x3».

## Задача 5. Сеть - `core/net.py`

- `symmetries(board)` - 8 полей (повороты, отражения), `inverse` для каждой.
- `encode(boards)` - поле с точки зрения ходящего: 2 плоскости «свои»/«чужие».
- `ValueNet(n, kind)`: 3x3 - плотная 18 -> 64 -> 64 -> 1, 5x5 - свёртки 3x3
  2 -> 32 -> 32 -> 32, плотный выход; выход tanh. `save`/`load` в `.npz`.
- `move_values(net, board)` - оценка каждой свободной клетки (после хода, за ходящего),
  `NetPlayer` - ход с наибольшей оценкой.
- Тесты: 8 разных полей для несимметричного, обратимость, симметрии не меняют исход;
  кодировка с точки зрения ходящего; сеть выбирает только свободную клетку, даже если
  занятая клетка оценена выше всех; сохранение и загрузка дают те же оценки.
- Коммит «Сеть оценки позиции после хода, симметрии, выбор хода».

## Задача 6. Обучение самоигрой - `train/selfplay.py`

- В начале файла `os.environ.setdefault` для трёх переменных потоков до импорта numpy.
- Самоигра пачкой партий сразу (все кандидаты всех партий - одним проходом сети),
  ε от 0.3 к 0.05. Цели - λ-возврат по цепочке «лучший ответ соперника» с дисконтом
  (λ и γ подбираются на проверке), 8 симметрий на позицию, MSE, Adam.
- Снимки уровней по числу партий, проверка каждого снимка, кривая обучения, паспорт
  `models/<поле>.json` и веса `models/<поле>-<уровень>.npz`.
- Тесты (быстрые, на маленьком числе партий): цели λ-возврата на готовой партии
  (победа, ничья, знак по очереди ходов); короткое обучение 3x3 улучшает игру против
  случайного; паспорт содержит все уровни, кривую и итоги проверок.
- Коммит «Обучение самоигрой, снимки уровней, паспорт».

## Задача 8. Данные игры - `game/settings.py`, `game/stats.py`

- Настройки: громкость, тема, задержка хода сети, мысли сети, первый ход по умолчанию;
  битый файл или чужие типы -> значения по умолчанию; запись атомарная.
- Статистика: по полю и уровню - партии, победы, поражения, ничьи, серия побед и лучшая
  серия; битый файл -> пустая статистика.
- Коммит «Настройки и статистика игрока: запись сразу, битый файл не мешает».

## Задача 9. Звуки - `game/sound.py`

- Синтез numpy: ход X, ход O, победа, поражение, ничья; WAV в памяти; QSoundEffect,
  громкость из настроек; нет звука в системе - молча.
- Тесты: длина каждого звука, без щелчков на краях (затухание), корректный WAV.
- Коммит «Звуки синтезом».

## Задача 10. Партия без окна - `game/session.py`

- Кто за X (я / сеть / по очереди), ход человека, ход сети, конец партии, выигрышная
  линия, запись в статистику ровно один раз.
- Тесты: партия до конца, «по очереди» меняет цвет, ход в занятую клетку не проходит,
  статистика пишется один раз.
- Коммит «Партия: очередь ходов, человек и сеть, итог в статистику».

## Задача 11. Место окна - `game/window_state.py`

- Правило `restore` из AiCar `tk_window_state.py` строка в строку, рабочие области
  экранов у Qt, запись при закрытии.
- Тесты: мусор, окно на отключённом мониторе, размер больше экрана, закрыли -> открыли
  там же (offscreen).
- Коммит «Окно открывается там, где его закрыли».

## Задача 12. Окно Qt - `game/`

- Темы QSS (тёмная, светлая), поле рисуется QPainter: крестики, нолики, подсветка
  выигрышной линии, мысли сети цветом и числом, цифры 1-9 на 3x3.
- Экраны: меню, партия, статистика (таблица, серия, кривая обучения, итоги проверок),
  настройки. Интерфейс на русском.
- Тесты: каждый экран рисуется в обеих темах, партия мышью и цифрами до конца, «Ещё
  раз» и «В меню», настройки сохраняются сразу.
- `main.py` с `--selftest <файл>`: окно offscreen, партия сети против бота, итог в файл.
- `tools/make_previews.py`: кадры экранов в `docs/preview_*.png`.
- Коммиты по экранам.
