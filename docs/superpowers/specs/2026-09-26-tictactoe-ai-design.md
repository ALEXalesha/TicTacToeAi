# Крестики-нолики с нейросетью - спецификация

Дата: 2026-09-26
Статус: утверждено (ответы Алексея 26.09: сеть учится сама с собой с нуля; правила - обычный
код; поля 3x3 и 5x5 «4 в ряд»; статистика, настройки и звуки; окно не на pygame - Qt, как
у нейро-змейки)

## 1. Что это

Алексей играет в крестики-нолики против своей нейросети. Сеть не знает ни одной стратегии:
она учится, играя сама с собой тысячи партий, только по исходу партий. Два поля:

- **3x3**, три в ряд - классика; сильная сеть не проигрывает никогда;
- **5x5**, четыре в ряд - игра сложнее, здесь видно, насколько сеть научилась.

Правила (чей ход, свободна ли клетка, победа, ничья) - обычный код в `core/rules.py`.

## 2. Стек

Python 3.13, numpy (свои сети: слои, обратное распространение, Adam - без PyTorch),
PySide6 (Qt 6) для окна, QtMultimedia для звуков (синтез numpy). pytest, PyInstaller +
NSIS, как у AiCar и нейро-змейки.

## 3. Устройство

| Папка / файл | Что делает |
|---|---|
| `nn/` | свои слои: плотный, свёртка 3x3, ReLU, tanh, Adam, сохранение `.npz` |
| `core/rules.py` | поле (N x N, int8: 0 пусто, 1 X, -1 O), ходы, победа (k в ряд), ничья |
| `core/net.py` | сеть оценки позиции и выбор хода |
| `core/bots.py` | случайный бот, бот «выиграй или помешай» (1 ход вперёд), минимакс для 3x3 - только для проверок и статистики, сеть у них не учится |
| `train/selfplay.py` | обучение самоигрой, снимки уровней, паспорт `models/<поле>.json` |
| `game/` | окно Qt: меню, партия, статистика, настройки, звуки, место окна |
| `models/` | обученные веса и паспорта - часть репозитория |
| `tests/` | pytest |

## 4. Сеть и обучение

Сеть оценивает позицию **после хода** («что будет, если я пойду сюда»): вход - поле с точки
зрения ходящего (свои = 1, чужие = -1, пусто = 0; 2 плоскости «свои»/«чужие» для свёртки),
выход - одно число в (-1, 1): ожидаемый исход для того, кто только что сходил. Ход -
клетка с наибольшей оценкой среди свободных. Для 3x3 - плотная сеть 18 -> 64 -> 64 -> 1;
для 5x5 - свёртки 3x3 (2 -> 32 -> 32 -> 32) и плотный выход.

Обучение: самоигра с долей случайных ходов (ε от 0.3 к 0.05); после партии каждая
позиция учится к исходу партии (TD(λ) или просто итог партии с дисконтом - что даст лучший
результат на проверке, решает разработчик и пишет в паспорт); 8 симметрий поля (повороты,
отражения) - одна позиция даёт 8 примеров.

Уровни - снимки одного обучения: «новичок» (рано), «средний», «сильный» (конец). Каждый
снимок проверяется и записывается в паспорт:

- 3x3: «сильный» против минимакса - 0 поражений за 200 партий обоими цветами; против
  случайного - не меньше 95% побед ходя первым;
- 5x5: «сильный» против случайного - не меньше 95% побед; против бота «выиграй или
  помешай» - побед больше, чем поражений;
- «новичок» заметно слабее «сильного» (паспорт показывает разницу).

Кривая обучения (доля побед против случайного и против бота по шагам) - в паспорте и в
статистике.

## 5. Игра (окно Qt)

- **Меню**: Играть, Статистика, Настройки, Выход.
- **Партия**: выбор поля (3x3 / 5x5), уровня сети, кто ходит первым (я / сеть / по
  очереди); ход мышью или цифрами на клавиатуре (3x3); пока сеть «думает» - короткая
  пауза, чтобы ход было видно; подсветка выигрышной линии; кнопки «Ещё раз» и «В меню».
  По настройке - «мысли сети»: оценка каждой свободной клетки цветом и числом.
- **Статистика**: партии, победы, поражения, ничьи - по полю и уровню; серия побед; кривая
  обучения из паспорта; итоги проверок сети.
- **Настройки**: громкость, тема (тёмная / светлая), задержка хода сети, показывать мысли
  сети, первый ход по умолчанию. Сохраняются сразу.
- **Звуки** (синтез): ход X, ход O, победа, поражение, ничья.
- Данные: `%LOCALAPPDATA%\TicTacToeAi` (`settings.json`, `stats.json`, `window.json`); с
  `portable.txt` рядом с exe - папка `saves` рядом. Битый файл - значения по умолчанию.
- Окно открывается там, где его закрыли (правило как в AiCar `tk_window_state.restore`).
- Интерфейс на русском.

## 6. Проверки

- `nn`: градиенты с численными, сохранение/загрузка.
- `rules`: победы по строкам, столбцам, диагоналям на 3x3 и 5x5 (4 в ряд, в том числе не
  от края), ничья, занятая клетка, чей ход.
- `net`: симметрии дают 8 разных полей и обратимы; сеть выбирает только свободную клетку.
- обученные модели - пороги из п. 4 (партии быстрые, тесты не дольше минуты).
- `game`: без экрана (Qt offscreen) - партия до конца, статистика и настройки сохраняются
  и переживают битый файл, звуки нужной длины, каждый экран рисуется, место окна.
- Мутационная проверка: намеренно ломаем правило победы, градиент, запись статистики -
  тесты краснеют.

CI - pytest на Windows: `.github/workflows/ci.yml` и копия `.gitea/workflows/ci.yml` с
`runs-on: windows`.
