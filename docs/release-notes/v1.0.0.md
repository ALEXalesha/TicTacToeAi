First release: tic-tac-toe against a neural network that taught itself by self-play, with no strategy given.

- **Two boards**: 3×3 (three in a row) and 5×5 (four in a row), three network levels each - novice, medium, strong.
- **3×3 strong never loses**: checked by exhaustive search over every opponent move; 200 draws out of 200 games against minimax; 98.5 % wins moving first against a random player.
- **5×5 strong**: 200 / 0 / 0 against a random player, 183 wins, 6 draws, 11 losses against a bot that always takes a win and blocks a threat.
- **Network's thoughts**: every free cell shows how the network rates a move there, from −1 to +1.
- **Statistics**: your games by board and level, win streaks, the network's learning curve and check results.
- Dark and light themes, synthesized sounds, keyboard moves on 3×3, the window reopens where it was closed.
- The interface is in Russian.

**Downloads**

- `TicTacToeAi-1.0.0-setup.exe` - installer; no admin rights, installs into the user profile.
- `TicTacToeAi-1.0.0-portable.zip` - unzip and run `TicTacToeAi.exe`; settings and statistics stay in the `saves` folder next to it.

Первый выпуск: крестики-нолики против нейросети, которая научилась сама, самоигрой, без единой стратегии.

- **Два поля**: 3×3 (три в ряд) и 5×5 (четыре в ряд), по три уровня сети - новичок, средний, сильный.
- **Сильная сеть 3×3 не проигрывает никогда**: проверено полным перебором всех ходов соперника; против минимакса 200 ничьих из 200; первой против случайного - 98.5 % побед.
- **Сильная сеть 5×5**: против случайного 200 / 0 / 0, против бота «выиграй или помешай» 183 победы, 6 ничьих, 11 поражений.
- **Мысли сети**: в каждой свободной клетке оценка хода туда, от −1 до +1.
- **Статистика**: ваши партии по полю и уровню, серии побед, кривая обучения сети и итоги её проверок.
- Тёмная и светлая темы, звуки синтезом, ход цифрами на 3×3, окно открывается там, где его закрыли.

**Файлы**

- `TicTacToeAi-1.0.0-setup.exe` - установщик; прав администратора не просит, ставится в профиль пользователя.
- `TicTacToeAi-1.0.0-portable.zip` - распаковать и запустить `TicTacToeAi.exe`; настройки и статистика остаются в папке `saves` рядом.
